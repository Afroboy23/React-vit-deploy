# Create a Hidden ByCreair Demo

**Trigger:** Use this workflow when the user asks to create a new hidden ByCreair demo, or provides a template like:
`Create a new hidden ByCreair demo using my official workflow.`

**Required Inputs:**
- Client name
- Business type
- Hidden slug (a random 5-character string, optionally generated by the user or by the assistant)

## Steps to Execute:

1. **Format Variables:**
   - Format the `[ClientName]` in PascalCase for the Component Name (e.g., RunBuddyDemo).
   - Format the `[clientname]` in lowercase without spaces for the route (e.g., `runbuddy`).
   - Use the provided `[random5]` slug or generate one (e.g., `x92lm`).

2. **Create the Demo Component:**
   - Use the `write_to_file` tool to create `src/pages/demos/[ClientName]Demo.jsx`.
   - If the `demos` folder doesn't exist, it will be automatically created.
   - The React component should be a basic, professional placeholder related to `[Business type]` or an iframe container if an external link is provided.

3. **Wire into `App.jsx`:**
   - Use `replace_file_content` or `multi_replace_file_content` to modify `src/App.jsx`.
   - Add the import statement: `import [ClientName]Demo from './pages/demos/[ClientName]Demo';`
   - Add the hidden route inside the `<Routes>` block: 
     `<Route path="/demo/[clientname]-[random5]" element={<[ClientName]Demo />} />`

4. **Confirmation & Expiry Reminder:**
   - Confirm to the user that the demo route is ready.
   - Provide the exact link: `bycreair.com/demo/[clientname]-[random5]`
   - Remind the user to set a manual Google Calendar reminder for 14 days from today called `EXPIRE DEMO: [Client Name]` so they remember to remove the route later.
